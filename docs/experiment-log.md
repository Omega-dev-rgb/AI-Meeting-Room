# 実験ログ

note記事の素材。オーナーの介入、止まった原因、AIの失敗を正直に残す。

## 指標

- **介入**：オーナーが答えた確認の数と内容
- **自走**：確認なしで完了したタスク数
- **つまずき**：AIが失敗・やり直した点と原因
